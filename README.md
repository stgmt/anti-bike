# Anti-bike: найти код, который агент написал вместо готового

Ищет в транскриптах Claude Code «велосипеды»: случаи, когда агент написал свою
функцию или класс там, где в том же репозитории уже лежало готовое.

Работает на трёх шагах, два из которых без модели:

1. **Своё.** Все функции из `Write` и `Edit` транскрипта — и верхней сессии, и
   её субагентов. Тела вырезаются по скобкам для JS/TS и по отступам для Python.
2. **Готовое.** Все функции репозитория, куда писалось, кроме тестов, копий в
   `worktrees/`, `var/tmp`, `_backup` и файлов, появившихся **после** окна.
3. **Форма.** Токены сводятся к классам (имя → `ID`, число → `LIT`), сравнение —
   Жаккар с весом по редкости токена. Отвечает «похоже ли строение».
4. **Модель.** Две пары тел, вопрос «одна и та же работа?». Отвечает на то, чего
   форма не может.

## Что доказано, а что нет

Замер 2026-11-02 по всем сессиям автора: 1 205 транскриптов → 123 окна с кодом →
105 находок формы → 77 пар → 23 после правила подключённости → **1 велосипед**.

| Утверждение | Доказательство |
|---|---|
| Детектор находит настоящий велосипед | `TeamOperationQueue` → `KeyedMutex`, сходство 0,602 |
| Форма сама не отделяет велосипед | настоящий 0,602 при шуме до 1,000 |
| Порог не спасает | при 0,65 велосипед пропадает, шум остаётся |
| Точность измерена | **нет**: одна точка разметки |
| Полнота измерена | **нет**: проверено на транскриптах, не на всём коде |

Графики: `reports/assets/`. Разбор: `reports/detector-20261102.md`.

## Команды

```bash
npm test        # контракты детектора, без сети
npm run types   # tsc --noEmit
```

Прогон по всем транскриптам (бесплатно, ~3,5 минуты):

```bash
ANTIBIKE_PROJECTS="$HOME/.claude/projects" node --experimental-strip-types scripts/scan-all.ts scan.json scan.txt
```

Проверка пар моделью (платно, одна короткая задача на пару):

```bash
ANTIBIKE_KEY_FILE=<env с ключом OpenRouter> node --experimental-strip-types scripts/arbitrate.ts scan.json arb.json
```

Посмотреть одну пару глазами:

```bash
node --experimental-strip-types scripts/show-pair.ts <транскрипт> <репозиторий> <своё> <готовое>
```

## Структура

```
src/
  bodies.ts     тела функций: скобки для JS/TS, отступы для Python
  tokens.ts     токены, классы, Жаккар с весом по редкости
  detect.ts     своё против готового, правило подключённости
  history.ts    ось времени: было ли готовое на момент окна
  verdict.ts    арбитр-модель, кеш и повтор на 429
scripts/
  scan-all.ts     прогон по всем транскриптам
  arbitrate.ts    проверка пар моделью
  show-pair.ts    обе стороны пары
  detect-repo.ts  один репозиторий против одного окна
test/           контракты: токены, разбор тел, ось времени
reports/        замеры и графики
```

## Чего здесь больше нет

Первый путь — `Stop`-хук, текст агента, jscpd и модель-классификатор — удалён
2026-11-02. Он не нашёл ни одного велосипеда: на подтверждённом случае jscpd дал
0 перекрёстных совпадений, потому что имена у клона другие. Подробности —
`reports/detector-20261102.md`, раздел 9.
