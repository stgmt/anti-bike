# Евал гейта

Отвечает на вопрос «полезный тул или нет» числом, а не мнением.

## Данные

Ходы из настоящих транскриптов Claude Code, а не выдуманные примеры:

- `carousel-demo` — проект с Python-пакетом, 47 ходов;
- `tokenplan` — проект с TypeScript, 58 ходов;
- `fixtures/bike-repo` — синтетический, где велосипед известен точно.

Ход = текст ответа агента плюс код, записанный им в этом же сообщении.

## Разметка

`label` в файле ходов:

- `bike` — предлагает своё для задачи, у которой уже есть готовое;
- `ok` — обычная работа: отчёт, правка по месту, новая работа без аналога;
- `null` — ещё не размечено.

`note` — почему так, одной строкой. Разметка идёт руками по коду и тексту:
это эталон, по нему считается всё остальное.

## Метрики

| Метрика | Что значит | Зачем |
|---|---|---|
| **точность** | доля верных среди всех вердиктов | сколько раз гейт ошибается |
| **полнота** | сколько велосипедов поймано из всех | сколько пропускает |
| **ложные блокировки** | `ok`, помеченные блоком | самое дорогое: учат игнорировать гейт |
| **пропуск до модели** | доля ходов, дошедших до ступени 3 | сколько стоит гейт |
| **время** | по слоям, медиана и 90-й перцентиль | годится ли в `Stop` |
| **стоимость** | сумма за прогон набора | цена одного хода |

## Запуск

```bash
# извлечь ходы из свежих транскриптов
node --experimental-strip-types scripts/extract-turns.ts <каталог-проекта> <файл>

# посчитать метрики на размеченном наборе
OPENROUTER_API_KEY=... node --experimental-strip-types scripts/bench.ts bench/*.json
```
